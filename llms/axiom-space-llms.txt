# Axiom Space

> Axiom Space, Inc. is a privately funded American space infrastructure developer headquartered in Houston, Texas, founded in 2016 by Kam Ghaffarian and former NASA ISS Program Manager Michael Suffredini. It is building Axiom Station — the world's first commercial space station and planned successor to the ISS — has flown private astronaut missions Ax-1 through Ax-4 to the ISS, and develops the Axiom Extravehicular Mobility Unit (AxEMU) spacesuit for NASA's return to the lunar surface. Commercial lines include human spaceflight, microgravity research, in-space manufacturing, and Orbital Data Centers (in-orbit cloud compute).

> Generated by the API Evangelist enrichment pipeline (2026-07-31) from Axiom Space's public website. Not published by Axiom Space.

## API surface

Axiom Space publishes **no public developer API**. As of 2026-07-31 the contract-discovery
pass found no OpenAPI/Swagger, no GraphQL endpoint, no MCP server, no A2A agent card, no
AsyncAPI or webhook catalog, no SDKs or client packages, no CLI, no sandbox, and no
developer portal, docs host, or API reference of any kind. `api.axiomspace.com`,
`developer.axiomspace.com` and `docs.axiomspace.com` do not resolve in DNS, and every
`/.well-known/` discovery path on the corporate site returns 404. All Axiom Space
offerings — including the Orbital Data Center product, whose only call to action is
"Talk to an ODC Expert" — are transacted through direct enterprise, agency, and
government engagement.

## Products

- [Axiom Station](https://www.axiomspace.com/axiom-station): The commercial space station under construction, successor to the ISS.
- [Axiom Suit (AxEMU)](https://www.axiomspace.com/axiom-suit): Axiom Extravehicular Mobility Unit, built on NASA's xEMU design for lunar surface operations.
- [Human Spaceflight](https://www.axiomspace.com/human-spaceflight): Private astronaut missions and crew services.
- [Microgravity Research](https://www.axiomspace.com/microgravity-research): Payload and research services in low Earth orbit.
- [In-Space Manufacturing](https://www.axiomspace.com/in-space-manufacturing): Orbital manufacturing services.
- [Orbital Data Centers](https://www.axiomspace.com/orbital-data-center): Cloud-enabled compute and storage in low Earth orbit; the ODC T1 node is built with Kepler Communications US Inc. and Skyloom Global Corp.
- [In-Space Data & Security](https://www.axiomspace.com/in-space-data-security): Cyber and quantum security, space communications, and orbital data services.
- [Missions](https://www.axiomspace.com/missions): Ax-1, Ax-2, Ax-3, Ax-4, Ax-5.
